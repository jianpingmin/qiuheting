# 秋禾汀 QIUHETING

> **江南水乡 · 时令水鲜 · 品质生活**

秋禾汀，是一个以江南水乡文化与时令水鲜为核心的年轻品质水产品牌，以大闸蟹为核心产品，逐步向更多优质水产品与品质生活方式延伸。

---

## 01 · 品牌简介

**品牌名称：** 秋禾汀  
**英文标识：** QIUHETING  
**核心品类：** 水产 / 大闸蟹  
**品牌定位：** 国潮 · 年轻 · 品质  
**核心场景：** 家庭消费 · 节庆礼赠 · 商务礼赠 · 电商零售  
**品牌气质：** 江南雅致、自然鲜活、简约现代、兼具传统底蕴与年轻表达

秋禾汀希望把江南水乡的自然气息、时令之美与优质水产连接起来，让传统水产以更年轻、更现代、更容易传播的方式进入日常生活。

---

## 02 · 品牌理念

### 见秋 · 见水 · 见鲜

**秋**，是时令，是一年中收获与丰盈的季节。  
**禾**，是生长，是土地与水乡共同孕育的生命。  
**汀**，是水岸，是江南水乡人与自然相依的生活场景。

秋禾汀，以时令为序，以水鲜为本，以品质为核心，将江南水乡的自然之美融入现代消费体验。

## 14 · 文件命名规范

统一采用：

```text
QHT_项目_内容_年份_版本
```

示例：

```text
QHT_Logo_Primary_2026.svg
QHT_Logo_White_2026.svg
QHT_Packaging_CrabBox_2026_V01.ai
QHT_Poster_MidAutumn_2026_V01.png
QHT_XHS_BrandStory_2026-09-01.md
```

### 版本规则

| 标识 | 含义 |
|---|---|
| V01 | 初始版本 |
| V02 | 修改版本 |
| V03 | 进一步修改 |
| FINAL | 最终确认版本 |
| ARCHIVE | 历史归档版本 |

正式发布文件建议使用 `FINAL`，历史文件原则上保留，避免失去品牌资产演进记录。

## 16 · Public 仓库使用规范

本仓库用于秋禾汀品牌资产的统一管理与版本记录。

由于仓库为 **Public**，上传任何文件前必须确认其适合公开访问。

### 禁止上传

- 密码
- API Key
- Access Token
- 私钥 / 证书私密部分
- 内部账号信息
- 未授权公开的个人信息
- 未公开的商业机密
- 不应公开的合同、财务及内部文件

### 对外发布前

所有品牌正式文件应经过确认后再进入 `FINAL` 或正式资产目录。
